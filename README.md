# Global Superstore Sales Performance Dashboard

## Project Overview

This project analyzes the Global Superstore dataset using Microsoft Excel.

## Objectives

- Perform basic data cleaning and validation
- Analyze sales performance
- Calculate descriptive statistics
- Analyze sales by region and category
- Analyze yearly sales trends
- Analyze quantity by category
- Create an interactive-style Excel dashboard

## Analysis Performed

- Duplicate check
- Missing-value analysis
- Total revenue calculation
- Average sales
- Mean, Median and Mode
- Sample variance
- Region-wise sales analysis
- Category-wise sales analysis
- Yearly sales trend
- Top 10 sales analysis
- Category-wise quantity analysis

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts
- Conditional Formatting
- Dashboard

## Dashboard

The dashboard presents key sales KPIs along with visualizations for region, category, yearly sales trend and quantity by category.
